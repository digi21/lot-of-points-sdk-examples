# Lot Of Points SDK examples

Examples of Lot Of Points extensions written against the Lot Of Points software development kit (SDK). Each example is
written in every supported language, so readers can compare the implementations of each extension:

- `cpp/`: C++20 extensions, built as dynamic-link libraries.
- `python/`: Python scripts.
- `dotnet/`: .NET assemblies.
- `xaml/`: the Extensible Application Markup Language (XAML) files of the panels and dialogs, shared by the three
  languages.

The examples will be added when version 0.3 of the SDK is released.
